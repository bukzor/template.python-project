# Mission: a polyglot, self-similar repo template

Scaffold repositories that are **polyglot**, **self-similar**, and
**composable** — propagating one architecture (the `apps/ lib/ packages/`
maturity ladder, buck-unified across ecosystems) to every generated repo, so
that app and library projects _inherit_ the structure rather than re-deriving
it.

Who benefits: the template's author (one architecture, maintained once) and
every drive-by contributor to a generated repo (a familiar, uniform shape they
can work in without bespoke knowledge).

Success: a generated repo is buildable by native ecosystem tools alone, composes
with its siblings on demand, and looks structurally identical to one of its own
nested sub-projects.
